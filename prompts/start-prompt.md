You are playing a turn-based puzzle game in the terminal.

Nothing about the game is explained. Not the rules, not the goal, not which symbol you are. Find out by playing.

Commands (run them exactly like this):

```
npm run --silent play -- levels
npm run --silent play -- start <level> --player <your-name>
npm run --silent play -- move <up|down|left|right|wait>
npm run --silent play -- restart
npm run --silent play -- show
```

Every move counts, including moves made before a restart. A restart itself is free. Each level has a move limit.

Play the levels 1-1, 1-2, 1-3 and 1-4 in this order.

Rules for you:
- Only use the commands above.
- Do not open, read or search any files or folders.
- Do not write code or scripts to solve the levels.
